01先认识它：每个按键干什么

背面那些「C」开头的键都能自定义，下面写的是建议用法。

顶部（从左到右）
模式旋钮

选 P / A / S / M 等拍摄模式。中间有锁定按钮，要按住才能转。

C2 键 可自定义

建议设成「对焦区域」，拍动物时随时切换。

C1 键 可自定义

建议设成「APS-C/Super 35mm」，一按就把画面放大 1.5 倍，拍远处的企鹅、鲸鱼用。

快门按钮 + 电源开关

半按对焦，全按拍照。外圈就是电源开关。

前转盘

快门按钮前面那个小拨轮。A 档时调光圈。

后转盘

右上角背面的拨轮。S 档时调快门速度，M 档时和前转盘分工。

曝光补偿拨盘 常被碰

右上角刻着 −3 到 +3。画面变亮/变暗就转它。它很容易在包里被蹭动，每次拍之前看一眼是不是在 0。

背面
MENU

进入完整菜单。菜单不能用手指点，只能用拨轮和摇杆操作。

C3 键 可自定义

MENU 左边那个。可以留给「白平衡」。

MOVIE（红点）

任何模式下按一下就开始录像，再按停止。别误按。

AF-ON

按住就对焦。配合「返回按钮对焦」拍动物非常好用，见第 05 章。

AEL

锁定曝光。逆光拍人时先对着人按一下，再重新构图。

多功能选择器（摇杆）

移动对焦框。按下去对焦框回到中间。

Fn

快捷菜单，12 个常用设置一屏搞定。拍照时 90% 的调整都从这里来。

控制拨轮

转动可改数值。上＝DISP 切换屏幕显示（找直方图）；左＝拍摄模式（单拍/连拍/自拍）；右＝ISO。

C4 / 删除

右下角。看照片时是删除键，拍照时可自定义。

播放 ▶

看照片。按快门半按就回到拍摄状态。

屈光度拨轮

取景器右侧。取景器里字看不清，就转它，近视的人特别要调。

翻转屏 + 眼感应器

眼睛靠近取景器，屏幕自动熄灭切到取景器。屏幕可以上下翻，低角度拍企鹅很方便。触摸只能点对焦位置，不能点菜单。

侧面与机身
右侧：双卡槽

卡槽 1 在下面，支持更快的 UHS-II 卡，放主卡。

左侧：接口

USB-C 可直接给机内电池充电，用手机充电头或充电宝都行。

镜头释放按钮

镜头左边。按住再逆时针拧下镜头。

底部：电池仓

电池型号 NP-FZ100。买备用电池认准这个型号。

模式旋钮上的每一格

AUTO全自动。借给别人帮你拍时用。
P程序自动。相机定光圈快门，你可以改曝光补偿和 ISO。
A光圈优先。这一趟最常用，风景、人像、动物都行。
S快门优先。拍飞鸟、鲸鱼、球赛这类快速动作。
M全手动。夜景、三脚架、瀑布慢门用。
1 / 2调出你存好的整套设置，比如把「南极动物」存在 1。
动态影像录像专用模式。
S&Q慢动作和快动作录像。

02手把手：菜单和快捷键怎么设

先学会这几种操作，后面所有设置都是同一个套路。按键名称：MENU 菜单键、Fn 功能键、中央键 控制拨轮中间那颗、▲▼◀▶ 按控制拨轮的上下左右。

① 菜单的基本操作

所有「MENU → … → …」的路径都这样走。

  1. 按 MENU。屏幕最上面一排是标签：拍摄设置1（相机图标）、拍摄设置2、网络、播放、设置（工具箱图标）、我的菜单（星星）。每个标签下还分好几页，右上角显示页码，比如 3/14。
  2. 按 ◀▶ 翻页、换标签；按 ▲▼（或转动控制拨轮）在一页里上下选项目。
  3. 选中项目后按 中央键 进入，再用 ▲▼ 选选项，按 中央键 确认。
  4. 按 MENU 返回上一层；半按快门 直接退出菜单回到拍摄。
找不到某项？菜单项目很多，同一个标签要翻好几页。慢慢按 ▶ 一页页看标题，名称和这本说明书里写的一样。

② 用 Fn 快捷菜单（每天最常用）

不进 MENU，一屏改 12 个常用设置。

  1. 拍摄时按 Fn，屏幕下方出现两排共 12 个小图标。
  2. 用摇杆或 ▲▼◀▶ 移到想改的那格（比如「对焦模式」）。
  3. 直接转前转盘或后转盘就能改数值；想看完整选项就按 中央键。
  4. 改完半按快门，回到拍摄。

③ 把 Fn 菜单换成你常用的 12 项

出厂的 12 项不一定顺手，换成这一趟用得上的。

  1. 按 MENU → 标签 拍摄设置2 → 翻页找到 功能菜单设置 → 中央键。
  2. 屏幕上是 12 个格子（上排 1–6，下排 7–12）。选一个格子，按 中央键。
  3. 出现功能列表，选你要放进去的功能，按 中央键 确认。列表很长，要按 ◀▶ 翻页。
  4. 重复，把 12 格都换好。按 MENU 退出。
格子建议放的功能
上排拍摄模式（单拍/连拍）· 对焦模式 · 对焦区域 · 人脸/眼部AF设置 · 曝光补偿 · ISO
下排测光模式 · 白平衡模式 · 创意风格 · 静音拍摄 · 文件格式 · 斑马线设定

④ 设置自定义键（C1 / C2 / C3 / C4）

把最常切换的功能放到实体按键上，戴手套也能一按就切。

  1. 按 MENU → 标签 拍摄设置2 → 找到 自定义键（静止影像） → 中央键。
  2. 出现按键列表：自定义按钮1（就是 C1）、自定义按钮2（C2）、自定义按钮3（C3）、自定义按钮4（C4），下面还有 AF-ON、中央按钮、左/右/下按钮等。选 自定义按钮1，按 中央键。
  3. 在功能列表里找到 APS-C/Super 35mm（列表很长，用 ◀▶ 翻页），按 中央键 确认。
  4. 回到按键列表，用同样方法设置其他键，按 MENU 退出。
  5. 试一下：退出菜单后按 C1，画面应该放大一圈，屏幕上出现 APS-C 字样。再按一次恢复。
按键建议功能为什么
C1APS-C/Super 35mm拍远处的企鹅、鲸鱼，一按放大 1.5 倍
C2对焦区域在「扩展自由点」和「区」之间快速切换
C3白平衡模式日落、雪地、室内灯光下快速改色温
C4眼控AF按住它强制找眼睛（人或动物）
按错了别慌同一个菜单里再改回来就好，自定义键不会影响照片和其他设置。

⑤ 把整套设置存到模式旋钮的「1」

第 03 章的设置都做完以后再做这一步。以后被调乱了，转到 1 就恢复。

  1. 先把模式旋钮转到你常用的档位（建议 A），把光圈、ISO、对焦等都调成想要的样子。
  2. 按 MENU → 标签 拍摄设置1 → 找到 存储 → 中央键。
  3. 选编号 1，按 中央键 确认存好。
  4. 使用：按住模式旋钮中间的锁定钮，转到「1」。屏幕会显示存好的设置，按 中央键 确认即可开拍。
  5. 想再存一套（比如南极动物：S 档、1/2000、连拍），就调好后存到 2。

⑥ 我的菜单：把常翻的项目收藏起来

像「间隔拍摄功能」「格式化」这种藏得深的，收藏到一页里。

  1. 按 MENU → 最右边星星标签 我的菜单 → 添加项目 → 中央键。
  2. 在列表里找到要收藏的项目，按 中央键，再选放在哪个位置。
  3. 以后按 MENU 再按 ◀ 就能跳到我的菜单。

建议收藏：间隔拍摄功能 · 格式化 · 静音拍摄 · 飞行模式 · 发送到智能手机 · 清洁模式。

⑦ 格式化存储卡（每张新卡先做一次）

  1. 按 MENU → 标签 设置 → 格式化 → 选卡槽 1 或 2 → 确定。
  2. 格式化会删掉卡里所有照片，只对新卡或已经备份过的卡做。

03出发前一次设好

在飞机上照着清单一条条设。不会操作菜单的话先看 第 02 章。打勾会保存在这台手机的浏览器里。

存成一键调出设好后：MENU → 拍摄设置1 → 存储 → 存到「1」。以后不管被谁乱调，转到模式旋钮的 1 就回来了。可以再按南极动物的设置存一套到「2」。

04曝光：三个数决定亮暗

光圈、快门、ISO 共同决定一张照片多亮。每个数除了影响亮度，还各有一个副作用，这个副作用才是你选它的理由。

光圈f/2.8 … f/16

镜头开的洞有多大。数字越小，洞越大，越亮，背景越虚。

拍人想要背景虚化：开大（f/2.8–4）。拍风景要前后都清楚：缩小（f/8–11）。

f/2.8 背景虚f/8 全清楚

快门速度1/4000 … 30″

感光多长时间。越快越能定格动作，越慢越容易糊。

手持安全线：大约 1/焦距 秒（有防抖可再慢一点）。动的东西要 1/500 以上，飞鸟 1/2000。

1/2000 定格1″ 拉丝

ISO100 … 51200

把信号放大多少倍。越高越亮，但噪点越多。

A7M3 在 ISO 6400 以内都很干净，12800 也能用。晚上别怕开高 ISO，糊了比有噪点更没救。

100 最干净12800 可用

曝光补偿：最该学会的一个功能

在 A、S、P 档，相机自动决定亮度，但它会把一切都拍成「中等灰」。所以：

场景相机会犯的错你要做的
雪地、冰山、白色企鹅肚皮拍成灰蒙蒙的拨盘拨到 +1 ~ +2
夜景、时代广场霓虹、黑衣服拍得发白、霓虹过曝拨到 −0.7 ~ −1
日落、逆光剪影天空过曝拨到 −1
普通白天基本正确保持 0

看直方图，别信屏幕亮度

按控制拨轮上的 DISP 几下，直到屏幕上出现一个小山形图。山贴着最右边＝有地方白得没细节了；贴着最左边＝黑死了。在南极强光下屏幕看着很暗，靠直方图和斑马线判断，不要靠眼睛。

05对焦：让该清楚的地方清楚

对焦模式（在 Fn 菜单里）

模式意思什么时候用
AF-S 单次AF对上焦就锁住风景、建筑、静止的人
AF-C 连续AF一直跟着主体对焦推荐默认：动物、人、球赛
DMF 直接手动对焦先自动，再拧对焦环微调微距、细节
MF 手动对焦完全自己拧夜景星空、隔着玻璃

对焦区域：告诉相机看哪里

区域适合
广域相机自己找主体。人像和单一主体好用，背景杂乱时会乱跳。
区在一块区域里找。飞鸟、鲸鱼出水，位置不确定时用。
中间只看画面中间。
自由点 S/M/L一个点，用摇杆移动。隔着草丛、栏杆对焦。
扩展自由点一个点加一圈辅助。拍企鹅、海豹的首选。
锁定AF框住主体后一路跟踪。主体在画面里移动时用。

眼部对焦

先确认固件是 3.0 以上（MENU → 设置 → 版本）。在 拍摄设置1 → 人脸/眼部AF设置 → AF时人脸/眼睛优先 设为「开」，AF-C 下半按快门就会自动找人眼。

拍动物时，同一页的「拍摄主体检测」改成「动物」。官方说法是针对猫狗等动物，对企鹅、海豹效果时好时坏，认不出时就切回扩展自由点。

返回按钮对焦（进阶，拍动物强烈推荐）

把对焦从快门上拿掉，改用拇指按 AF-ON：

  1. 拍摄设置1 → 半按快门AF 设为「关」。
  2. 以后：拇指按住 AF-ON＝对焦并跟踪，食指只管按快门。
  3. 好处：企鹅不动时松开拇指，焦点就锁住了，可以随意重新构图；它一动再按住，马上跟上。
注意改了之后，别人借你相机按快门会对不上焦。借人前把这项改回「开」，或者直接转到 AUTO。

06行程场景速查

按日期排。黑色标签是建议参数，橙色是曝光补偿。镜头光圈不够大时，用镜头的最大光圈即可。

07南极专章：保护相机和电池

−8 ℃、海水飞溅、强反光、一天 18 小时日照，再加上从冷甲板进到暖船舱。下面每一条都是为了不在最关键的时候掉链子。

电池

  • 至少带 3 块 NP-FZ100。低温下一块电池可能只剩一半电量。
  • 备用电池放在贴身内层口袋，用体温捂着。冷掉的电池回暖后电量会回来，不是坏了。
  • 每次登陆前换上满电的那块。在冲锋艇上、雪地里尽量不要开电池仓。
  • 省电：网络 → 飞行模式 → 开；屏幕亮度别开最高；设置 → 自动关机开始时间 设 1 分钟。
  • 坐飞机：备用电池只能随身带，不能托运。NP-FZ100 约 16.4 Wh，远低于航空 100 Wh 的限制。

冷凝（最容易被忽略、最伤相机）

进船舱之前在甲板上把相机装进防水袋或密封袋，把袋口封好再进门。让它在袋子里慢慢回暖 1–2 小时，镜头和机身内部才不会起雾结水。回暖前不要开袋、不要换电池或存储卡。

所以，换卡、换电池、换镜头都在船舱里、出门前做好。

雪地曝光

  • 曝光补偿 +1 ~ +1.7，看直方图：山要靠右，但别贴死在最右边。
  • 打开斑马线：拍摄设置2 → 斑马线设定 设「开」，等级 100+。屏幕上出现斜条纹的地方就是过曝了，补偿往回拨一点。
  • 偏振镜能压住冰面反光、让天空更蓝。没有也没关系。

海水、雪和风

  • A7M3 只是「防尘防滴设计」，不是防水。冲锋艇上相机平时放在防水袋里，要拍才拿出来。
  • 登陆时不要换镜头，风会把雪和盐雾吹进传感器。一天用一支镜头。
  • 每天回舱后，用微湿的布擦掉机身上的盐，再擦干。镜头用镜头布，镜片上的盐粒先吹掉再擦，不要直接抹。
  • 传感器有脏点：设置 → 清洁模式 后用吹气球吹，别用嘴吹。

戴手套操作

  • 穿薄内层手套就能按键。触摸屏戴手套基本没用，重要功能都放进自定义键和 Fn，不要在甲板上翻菜单。
  • 相机背带挂在脖子上或缠在手腕上。冲锋艇上掉了就没了。

动物与规矩

  • 离野生动物至少 5 米，所以长焦最有用。没有长焦就用 C1 的 APS-C 模式，画面放大 1.5 倍（像素降到约 1000 万，够发朋友圈和冲印小尺寸）。
  • 把相机放低，翻转屏朝上，从企鹅的视线高度拍，比站着往下拍好看得多。
  • 开连拍（控制拨轮左键 → 连拍 Hi）。企鹅跳水、鲸鱼甩尾都在一瞬间，连拍后挑最好的一张。
  • 不能用闪光灯拍野生动物。

存储与备份

  • 双卡同时记录（见第 03 章），一张卡坏了还有另一张。
  • 每天晚上把当天照片导到手机或电脑，船上网络很慢，别指望上传云端。
  • 一天可能拍上千张，带够卡：RAW 每张约 25–50 MB，128 GB 大约能放 2500–4000 张。

08让照片好看的技巧

构图

  • 打开网格线：拍摄设置2 → 网格线 → 三等分线。把地平线放在上 1/3 或下 1/3，主体放在交叉点上。
  • 找前景：马丘比丘拍远山时，把近处的石墙、羊驼放进画面，照片立刻有层次。
  • 地平线要平：海上拍冰山最容易歪。按 DISP 调出水平仪。
  • 给动物留空间：企鹅朝哪边看，就在那边多留一点空。
  • 拍人别切在关节：不要正好切在膝盖、手腕。

光线

  • 日出后、日落前一小时光最暖最柔，叫「黄金时段」。南极 11 月的黄金时段在深夜，晚饭后上甲板。
  • 正午顶光拍人脸会有黑眼圈，让人站到阴影里，或者转个方向背对太阳，再加曝光补偿。
  • 阴天别收相机：冰山在阴天更蓝，色彩更饱和。

相机功能

  • RAW + JPEG：JPEG 直接发手机，RAW 留着回家调。雪地过曝、日落太暗，RAW 都救得回来。
  • 阶段曝光（控制拨轮左键 → 连续阶段曝光 3 张 ±1）：光比很大、拿不准时，一次拍暗、中、亮三张。
  • 拍完放大检查：播放时按印着放大镜图标的键放大，确认眼睛/细节是清楚的，再走。
  • 静音拍摄：拍摄设置2 → 静音拍摄 → 开。剧院导览、教堂、探戈秀用。只在 P/A/S/M 下可用；拍快速移动物体会变形，平时关掉。
  • 2 秒自拍：上三脚架或把相机放在栏杆上拍夜景，用自拍定时 2 秒，避免按快门时手抖。上三脚架时把 SteadyShot 关掉。
  • 间隔拍摄（延时）：拍摄设置1 → 间隔拍摄功能，间隔 1–60 秒、最多 9999 张。在船上拍冰山缓缓经过、天色变化，回家合成延时视频。

09视频：几个够用的设置

  • 按红色 MOVIE 键就能录，不用转模式旋钮。
  • 画质：拍摄设置2 → 文件格式 选 XAVC S 4K；记录设置 选 30p（或 25p）。
  • 慢动作：模式旋钮转到 S&Q，在 慢和快设置 里选 120fps。1080p 下拍鲸鱼甩尾、企鹅跳水、尼亚加拉的水，回放慢 4–5 倍。
  • 风大：拍摄设置2 → 减少风噪声 → 开。南极甲板上一定要开。
  • 录像时快门速度约为帧率的两倍（30p 用 1/60）。阳光太强、画面过曝时需要 ND 镜，没有就把 ISO 降到最低，再缩小光圈。
  • 录像时机身会发热、耗电更快，长时间录像多带电池。

10出问题了怎么办

按快门没反应
  1. 看屏幕有没有提示「无存储卡」或「存储卡已满」。
  2. 在 AF-S 下没对上焦时，相机可能不让拍。换 AF-C，或对着有反差的地方对焦。
  3. 是否开了返回按钮对焦？那就要先按 AF-ON。
  4. 是否在播放照片？半按快门回到拍摄状态。
屏幕突然黑了
  • 眼感应器被挡住了（背带、手指、外套），相机以为你在看取景器。
  • 可以设置成只用屏幕：MENU → FINDER/MONITOR → 显示屏（用完记得改回「自动」）。
  • 可能是自动关机，半按快门唤醒。
照片全白或全黑
  • 先看右上角曝光补偿拨盘，九成是被蹭到了 +3 或 −3。
  • 在 M 档：检查快门速度和 ISO 是不是还停在上次夜景的设置。
  • ISO 是不是被固定在很高的值？改回 ISO AUTO。
照片糊了
  • 整张都糊：快门太慢。看一下快门速度，低于 1/60 就提高 ISO。
  • 背景清楚、主体糊：焦点跑到背景上了。改用扩展自由点，把框放在主体上。
  • 主体在动：快门不够快，动物至少 1/500。
对焦框到处乱跳
  • 对焦区域在「广域」，背景太杂。改成「扩展自由点」或「区」。
电池掉电特别快
  • 天冷：换上贴身口袋里捂热的电池。
  • 打开飞行模式，降低屏幕亮度，缩短自动关机时间。
  • 录像、连拍、长时间看照片都很耗电。
某个菜单是灰色的，选不了
  • 功能互相冲突。比如开了静音拍摄就不能用闪光灯和 B 门；模式旋钮在 AUTO 时很多项都不能改。先转到 P/A/S/M。
被调乱了，想恢复
  • 如果按第 02 章 ⑤ 存过设置：直接把模式旋钮转到「1」。
  • 没存过：设置 → 出厂重置 → 相机设置重置，只恢复拍摄设置，不删照片。不要选「初始化」。
取景器里看不清
  • 转取景器右侧的屈光度拨轮，直到里面的文字清楚。

11把照片传到手机

  1. 手机装索尼官方 App：Imaging Edge Mobile（索尼较新的 App 叫 Creators' App，以应用商店里支持 ILCE-7M3 的那个为准）。
  2. 相机上看照片时，网络 → 发送到智能手机，选照片，用 App 扫屏幕上的二维码连接。
  3. 传 JPEG 就够发朋友圈，速度快。RAW 回家再用电脑导。
  4. 传完记得开回飞行模式，省电。
电脑导入用 USB-C 线连接电脑，或者直接用读卡器，最快。
菜单名称按 ILCE-7M3 中文帮助指南核对（固件 3.0 以上），不同固件版本个别名称或所在页面可能略有出入；按路径找不到时，在菜单里逐页找同名项目。官方中文帮助指南：helpguide.sony.net/ilc/1720/v1/zh-cn/ 。各场馆的拍照规定以现场为准。
